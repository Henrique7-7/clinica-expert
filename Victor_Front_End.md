Função
O profissional de Front-end é responsável pela parte visual e interativa do sistema, criando as telas que serão utilizadas pelos usuários.

Responsabilidades:
Desenvolver as telas do sistema
Criar a tela de login
Desenvolver a agenda de consultas
Criar os cadastros de pacientes e profissionais
Desenvolver a área de atendimentos
Criar uma interface simples e organizada

Conhecimentos e competências:
HTML
CSS
JavaScript
Lógica de programação
Responsividade
Usabilidade e acessibilidade

Entregas:
Telas do sistema
Formulários de cadastro
Interface de agendamento
Painel de acompanhamento

Contribuição para o projeto:
Na Clínica Expert, o Front-end facilita a utilização do sistema pelos funcionários da clínica, permitindo que eles acessem de forma clara as funções de cadastro, agendamento e acompanhamento dos atendimentos.

Trabalho em equipe:
O Front-end trabalha principalmente com o **Analista de Requisitos**, **Back-end**, **Banco de Dados** e **Testes e Qualidade** para desenvolver e validar as funcionalidades do sistema.

Sem essa função:
Sem o Front-end, os usuários teriam dificuldade para utilizar as funcionalidades do sistema, mesmo que sua estrutura interna estivesse funcionando.

LinkedIn:
Durante o desenvolvimento da Clínica Expert, estou atuando como Desenvolvedor Front-end, contribuindo para a criação das telas e interfaces do sistema.
Meu objetivo é desenvolver uma interface simples e organizada, facilitando tarefas como cadastro de pacientes, agendamento de consultas e acompanhamento dos atendimentos.
O trabalho em conjunto com as áreas de requisitos, Back-end, Banco de Dados e Testes é importante para que a solução seja funcional e fácil de utilizar.
