# Matheus — Analista de Requisitos

## Projeto: Sistema para uma Rede de Clínicas Populares

### O que esse profissional faz?

O Analista de Requisitos identifica as necessidades dos usuários e da empresa, entende os problemas existentes e define o que o sistema precisa fazer para solucioná\-los\.

No projeto da rede de clínicas, essa função transforma as necessidades da clínica em requisitos claros para que a equipe de desenvolvimento consiga entender e implementar a solução\.

### Principais responsabilidades

- Identificar os problemas enfrentados pela rede de clínicas\.
- Conversar com os possíveis usuários do sistema\.
- Levantar as necessidades da recepção, dos profissionais de saúde e dos gestores\.
- Definir os requisitos que o sistema deverá atender\.
- Organizar e documentar as funcionalidades\.
- Verificar se a solução proposta realmente atende ao problema identificado\.

### Conhecimentos e competências importantes

- Comunicação;
- Organização;
- Raciocínio lógico;
- Capacidade de análise;
- Conhecimento sobre processos de sistemas;
- Capacidade de transformar necessidades em requisitos claros\.

### Entregas

O Analista de Requisitos poderia produzir:

- Documento de requisitos;
- Lista de funcionalidades;
- Requisitos funcionais e não funcionais;
- Fluxos de utilização do sistema;
- Critérios para validar se as funcionalidades atendem às necessidades\.

### Como ajuda o projeto?

No caso da rede de clínicas, o Analista de Requisitos pode identificar que o sistema precisa, por exemplo:

- Permitir o cadastro de pacientes;
- Controlar horários disponíveis;
- Impedir conflitos de agendamento;
- Enviar lembretes;
- Registrar os atendimentos realizados\.

### Com quem trabalha?

O Matheus precisaria trabalhar principalmente com:

- **Victor — Front\-end:** para explicar como as funcionalidades deverão ser apresentadas nas telas\.
- **Luiz — Back\-end:** para definir as regras e comportamentos que o sistema deverá executar\.
- **João — Testes/Qualidade:** para estabelecer critérios que permitam verificar se os requisitos foram implementados corretamente\.

### O que poderia acontecer sem essa função?

Sem uma análise adequada, a equipe poderia desenvolver funcionalidades desnecessárias, esquecer necessidades importantes ou interpretar o problema de maneira incorreta\.

Isso poderia gerar retrabalho e fazer com que o sistema não resolvesse os principais problemas da clínica\.
