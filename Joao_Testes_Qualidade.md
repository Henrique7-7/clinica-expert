

Função

O profissional de Testes e Qualidade verifica se o sistema funciona corretamente e atende aos requisitos definidos pela equipe.

Responsabilidades

Testar as funcionalidades do sistema
Verificar conflitos de horários
Testar cadastros, agendamentos e cancelamentos
Identificar e registrar erros
Verificar se os problemas foram corrigidos

Conhecimentos e competências
Raciocínio lógico
Atenção aos detalhes
Organização
Conhecimento básico de testes de software
Capacidade de identificar problemas

Entregas

Cenários de testes
Relatórios de erros
Resultados dos testes
Validação das funcionalidades

Contribuição para o projeto

Na Clínica Expert, os testes ajudam a garantir que o sistema funcione corretamente e evitem problemas como agendamentos duplicados ou informações incorretas.

Trabalho em equipe

O profissional trabalha com o Analista de Requisitos, Front-end e Back-end para verificar se a solução atende ao que foi planejado.

Sem essa função

Erros poderiam passar despercebidos e chegar aos usuários, causando problemas no funcionamento do sistema e retrabalho para a equipe.

LinkedIn

Durante o desenvolvimento da Clínica Expert, estou atuando na área de Testes e Qualidade. Minha função é verificar se as funcionalidades do sistema estão funcionando de acordo com os requisitos definidos.

Um dos principais pontos será testar os agendamentos, verificando situações como horários disponíveis, conflitos, cancelamentos e alterações.

A área de qualidade é importante para identificar problemas antes que eles cheguem aos usuários e contribuir para uma solução mais confiável.
